About

TheKeyMachine

TheKeyMachine is an open source toolset built for 3D animators working in Autodesk Maya. It brings together animation, rig, selection, graph editor and workflow tools in a compact Maya interface.

The project was created by Rodrigo Torres and released under the GPL 3.0 license. This website branch is a static backup for the public site, updated to point at the current GitHub release data and documentation.

What it includes

TKM includes everyday animation helpers like isolate, snap, reset, counters, temporary pivots, follow camera, animation offsets, copy and paste animation, copy and paste world position, sliders for tween and blend, customizable menus and selection tools.

Recent releases also include tools like Snapshot Rig, Anim Layer Weights, Global Curve and Temporal Controls, alongside fixes for toolbar loading, callbacks, tracers, mirrored pasting and layer-aware operations.

Compatibility

Current releases include builds for Maya 2022 through 2027 on Windows, Linux and macOS.
