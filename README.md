# TheKeyMachine Website

Static website branch for TheKeyMachine.

This branch is independent from the application source branches and contains only the files needed for GitHub Pages.

Pages:

- `index.html`
- `changelog.html`
- `help.html`
- `about.html`
- `site.js`
- `releases.json`

Assets:

- `images/web_logo_230.png`
- `images/favicon.png`
- `images/github.svg`
- `images/youtube.svg`
- `images/instagram.svg`
- `images/discord.svg`

The homepage and changelog use `releases.json` for current release data, with static HTML content kept as a fallback.
