# TheKeyMachine Website

Static website branch for TheKeyMachine.

This branch is independent from the application source branches and contains only the files needed for GitHub Pages.

Pages:

- `index.html`
- `changelog.html`
- `help.html`
- `about.html`

Assets:

- `images/web_logo_230.png`
- `images/favicon.png`
- `images/youtube.png`
- `images/instagram.png`
- `images/discord.png`

The homepage links to the latest GitHub release. The changelog links each version title directly to that release zip.
