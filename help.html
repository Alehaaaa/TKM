Quick install checklist

  1. Download the latest release zip from the homepage.
  2. Follow the GitBook install guide for personal or studio setup.
  3. Restart Maya after installation or after changing package paths.
  4. Use the update guide when moving an existing install to a newer release.

Known limitations from the docs

Nudge Box

The Nudge Box can displace keys when moving them. The tool is marked in the docs as under review.

Tracer

If a viewport is in isolate mode or motion trails are hidden, tracers might not be visible. Add them to the isolate set or change the view mode.

Temp Pivots

Temporary pivots may not align correctly in some scenes or object setups.

Animation Offset

The docs note that Animation Offset has no undo, works only when placed on top of a keyframe, and works with one object at a time.
