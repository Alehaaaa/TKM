Project Update & Domain Sunset

The Key Machine is no longer in active development. Due to a lack of funding to sustain server costs, this official domain (thekeymachine.xyz) will be permanently shut down around mid-September 2026.

The project will remain open-source, and all code will continue to be freely available on our GitHub repository. A huge thank you to everyone who used the toolset and supported the project along the way!


TheKeyMachine is an open source set
of tools designed for Maya animators.

These tools are crafted to accelerate and facilitate many of the tasks animators undertake on a daily basis.

TheKeyMachine is under GPL 3.0 license. Source code is available on Github: https://github.com/thekeymachine/TKM
