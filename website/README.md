# TheKeyMachine Website Backup

Static backup based on this Wayback Machine capture:

https://web.archive.org/web/20260606162128/https://thekeymachine.xyz/

Recovered pages:

- `index.html`
- `download.html`
- `donate.html`

The archived navigation also referenced `help.php` and `about.php`, but Wayback did not have those pages available for the requested capture. Local placeholder pages are included so navigation remains complete.

Archived image assets recovered locally:

- `images/web_logo_230.png`
- `images/favicon.png`
- `images/youtube.png`
- `images/instagram.png`
- `images/discord.png`

The referenced `images/download.png` and `images/stripe.png` were not available as images in Wayback; the backup uses static CSS fallbacks in their original positions.

The archived download page linked to `versions/current/TheKeyMachine_installer.zip`; that binary was not present in this repository and was not recovered into this backup.
