Open source animation toolset for Autodesk Maya

TheKeyMachine is a set of tools designed for Maya animators.

These tools are crafted to accelerate and facilitate many of the tasks animators undertake on a daily basis.

TheKeyMachine is under GPL 3.0 license. This site points to a maintained fork, with source code available on GitHub.

Latest release

0.1.46

Published August 22, 2026. Supports Maya 2022 through 2027 on Windows, Linux and macOS.

Animation workflow

Smart keying, copy and paste animation, world-space pasting, reset tools, temporary pivots and animation offsets.

Rig and scene helpers

Selection sets, follow camera, tracers, snapshot rig tools, custom menus and toolbar controls built for daily Maya work.

Graph Editor tools

Curve editing, tangent helpers, tween and blend sliders, cycle matching and newer global curve controls.
